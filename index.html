Public status-normalizer fixture

Test the workflow before claiming intelligence.

The fixture starts with a status function that returns its input unchanged. A predetermined one-line patch strips surrounding whitespace and converts the value to lowercase.

The check first reproduces the regression, then tests the repaired code. Independent checks run in a different workspace. Temporary approved and rejected records both restore; duplicate events and conflicting choices are blocked.

0 provider calls0 AI charges0 GitHub writes

Zero counts apply to this fixture check only. Scripted decisions are not human patch approvals. Local temporary workspaces are not host security sandboxes.

Before / expected regression
def normalize_status(value: str) -> str:
    return value
After / predetermined patch
def normalize_status(value: str) -> str:
    return value.strip().lower()
